# Task Page
Aplicação web de gerenciamento de tarefas com operações CRUD completas, desenvolvida com React.js e Tailwind CSS.

## Funcionalidades

- Criar tarefas com título e descrição
- Editar tarefas existentes
- Remover tarefas
- Visualizar detalhes de cada tarefa
- Persistência de dados via localStorage — os dados são mantidos mesmo após fechar o navegador


## Tecnologias

- **React.js** — componentização e gerenciamento de estado com hooks (useState, useEffect)
- **Tailwind CSS** — estilização utilitária e design responsivo
- **localStorage** — persistência de dados no navegador sem necessidade de backend
- **Vite** — bundler para desenvolvimento e build


## Como rodar localmente
***bash#*** Clone o repositório<br>
`git clone https://github.com/TalitaMoul/Task-Page.git`

## Acesse a pasta
`cd Task-Page`

## Instale as dependências
`npm install`

## Inicie o servidor de desenvolvimento
`npm run dev`
Acesse *http://localhost:5173* no navegador.

## Aprendizados
Este projeto foi desenvolvido para praticar o fluxo completo de um CRUD no front-end, incluindo gerenciamento de estado com hooks do React e persistência de dados com localStorage, sem depender de uma API externa.
